# QGH Simulator RT Study Reference

This is original simulator guidance, not an operational manual or a reproduction of the supplied reference pages. Use current authorised publications and local instructions for real aviation operations.

## Version-linked accepted calls

Open [Training Centre — Accepted RT Calls](training-centre.html#calls). The catalogue is the single maintained source of accepted examples, limitations, reply types and D/F behaviour. Its examples are tested against the same parser used by the simulator. Use Print Reference there for a printable copy.

## Training principles

- Speak one complete transmission. PTT releases the call for interpretation after the final words have arrived. A correction during the same transmission must be reconciled before movement.
- Normal QGH accepts heading-based turns. U/S Compass uses immediate left, right and stop commands without disclosing aircraft heading.
- Single-aircraft calls may omit the callsign. Tactical calls address one configured aircraft explicitly; similar numbers are not aliases.
- An information receipt is not a clearance. A report request arms a condition; it does not turn, climb or descend the aircraft.
- State a level reference: altitude in feet, height in feet, or flight level. The vertical model is a generic training approximation, not aircraft performance certification.
- Pilot transmissions drive the D/F indication. The last indication holds for two seconds after release. Ground indication remains off.
- Pilot audio is optional. Keep it muted with speakers; test and confirm headphones before enabling sound. The same captions and D/F remain when muted.
- Unsupported requests are labelled not simulated; the simulator must not claim to have flown them. Aircraft systems, landing and advanced speechless/PTT-click emergency procedures remain outside this version.

## Sources and limitations

Public aviation radiotelephony references inform terminology; applicability differs between authorities and units. User-provided study material informed requirements but is not redistributed here. A successful simulator exercise is not operational clearance or qualification.
