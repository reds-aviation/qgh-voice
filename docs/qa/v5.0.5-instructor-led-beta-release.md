# v5.0.5 — Instructor-led beta gateway

## Release scope

The established Individual Practice QGH workflow remains intact. The hosted web edition adds a web-only route to an independent Instructor-led ATC Training Suite beta at `/instructor-led/`.

The beta provides instructor and controller positions in two tabs of the same browser profile. It includes QGH/D/F, surveillance/SRA and PAR training views; up to 24 seeded aircraft; and separate PRIMARY (`+`), Mode A (`□`) and Mode S (`□`) training return treatments. It is a training representation, not a certified or operational ATC system.

## Limits of this beta

- The instructor and controller positions currently require two tabs in the same browser profile; they are not a cross-device relay.
- The beta has not been physically accepted on Android, iPhone/iPad or Windows hardware in this release cycle. Automated responsive and browser-level checks are not a substitute for those trials.
- No Windows installer or Android package is produced or published by this web-only release.
- GitHub Pages is the publication target for this release. Netlify publication is deliberately outside this release scope.
