Instructor-led training guide

Start & connect · Exercise modes · All typed commands · Keyboard · Student scope · Recovery & review

1. Set up and join

  1. Choose QGH, surveillance vectoring, SRA or PAR. Set 1–24 aircraft. Edit callsign, squawk (four octal digits 0–7), return type, aircraft type, initial bearing, range, heading, altitude, speed, turn rate and vertical rate. Bearing and heading are independent. Defaults use separate levels; check them before starting.
  2. Select the runway/final track and applicable sensor settings. The synthetic local boundary and centreline are training overlays, not published aerodrome limits.
  3. Create Session opens a dedicated Student Display. Enter the generated six-digit PIN there. Instructor selects Admit; student selects Ready; instructor selects Start.
  4. Both positions must use the SAME browser profile and site origin on one computer. A phone cannot join another device using this local PIN. Cloud/LAN sessions are not included yet. GitHub and Netlify pages are separate origins.
  5. For an extended monitor, select Open / Focus and then Move to Second Display. Allow placement if your browser asks. If unsupported, drag the student window manually. Keep the instructor window open.

Pilot audio is optional, installed-device only, and muted by default. Enable it on the student position if a local voice is available. Captions and simulated transmissions still work when audio is muted or unavailable. This beta is controlled by buttons and keyboard, not voice recognition.

2. Exercise modes and timing

QGH: existing Normal/U/S exercise flow, default 5× flight clock. Normal uses heading turns; U/S uses left/right NOW and STOP with no heading readback. D/F appears during the pilot transmission and freezes for two real seconds at release. Selecting another aircraft does not change the transmitting source.

Vectoring/SRA/PAR: default real-time 1×; optional 5× and 10× accelerate the flight and sensor clock together. Groundspeed remains knots, range NM, turn rate degrees/second and vertical rate ft/min. At 240 kt, one real minute at 1× covers 4 NM in straight flight. Advance One Minute advances every aircraft, not just the selected one.

Surveillance/SRA: returns update on beam crossing at the selected 10/12/15 RPM (6/5/4 simulation-second revisit). Primary + returns are anonymous. Cooperative secondary □ returns can show sampled identity and track data. They are not continuous truth.

SRA: centreline, distances and 3° descent cues are reference aids. The instructor must command descent; there is no automatic glidepath capture. Heights marked AAL are above aerodrome level, not an operational clearance.

PAR: for a vectoring-to-PAR exercise, start in Surveillance, vector inbound, then select Transfer PAR when the configured gate permits it (normally at or within 10 NM inbound). Direct PAR setup is also available. The designated aircraft stays tracked even when another aircraft is selected for control. Azimuth and elevation are sampled, not equipment-certified tolerances.

3. Typed commands

Select the aircraft first. Type into Command Bar and press Enter or Execute. Case and repeated spaces do not matter. This is an exact grammar, not free-form RT or callsign addressing. HELP or ? opens the quick reference. Invalid or unavailable commands make no change.

Accepted aliasesEffect / limits

Commands with numbers

  • L 230, LEFT 230, TURN LEFT 230, TURN LEFT HEADING 230; use R/RIGHT for the right variants. Optional TURN and HEADING also work with L/R. Heading must be 0–359°. Unavailable in U/S Compass.
  • SPD 240 or SPEED 240: 60–600 kt, multiples of 5.
  • ALT 7000 or ALTITUDE 7000: infer climb/descent from current level. 500–45,000 ft, multiples of 100.
  • CLIMB 7000, DESCEND 5000, MAINTAIN 7000: TO or AT may precede the number. The direction must match the current altitude; MAINTAIN requires the current level.

Buttons and fields

The turn buttons use Assigned Heading in Normal QGH/radar; U/S buttons turn immediately. Live Speed applies on change. Altitude sets the target; Climb To and Descend To execute it. Continue Heading uses the assigned-heading field. SRA/PAR additionally offer Continue Approach, Report Runway Visual and Missed Approach. Terminate is button-only; it ends the exercise and opens debrief. No keyboard shortcut terminates the exercise.

Shortcuts do not run inside inputs, selects, buttons, links or the command bar, while the guide is open, with modifier keys, or on held-key repeats. Finish typing and click a neutral area before using a shortcut. On phones, use buttons; turn the radar display to landscape.

5. Student display controls

QGH: switch QDM/Homing or QTE/True Bearing. Held readings use the frozen release observation, not a new aircraft position. Near overhead, a bearing may be unavailable.

Radar: select range and history Off/3/5, choose data-label fields, minimise labels, and tap a cooperative square to open details. Drag the detail-card handle to declutter. Primary plots have no identity data. Centreline/descent controls can hide only instructor-provided overlays. PAR provides range and history controls for azimuth/elevation. Pilot Audio toggles sound without removing captions.

6. Timing, recovery and debrief

  • Connected means the link is alive. Picture Stale or Simulation Stalled are separate warnings. No Signal in QGH and Awaiting Scan in radar can be normal.
  • A browser processing gap above two seconds pauses the exercise instead of silently losing or jumping flight time. Restore the instructor window and select Resume. This does not prevent device sleep.
  • Refresh the same student window to restore the admitted seat and last safe picture. Audio restarts muted. Use Reconnect for a lost link. If the window was closed or storage is unavailable, instructor can Release Student Seat, admit the new window and start again from the existing aircraft state.
  • Refreshing or closing the instructor ends the local session. Keep that window open. PIN admission expires after 15 minutes while waiting; an active admitted seat can reconnect.
  • New commands replace obsolete pilot replies. Flight actions execute immediately; audio completion never controls the turn itself. Muted captions use a bounded reading duration. Missing audio completion has a watchdog so D/F cannot stay live forever.
  • Terminate opens debrief: toggle truth, student observations and commands; play/pause, choose replay 1×/2×/3× or scrub time. Restart Exercise returns to setup.

Guide maintenance

The build stamps this guide with the beta version and generates the direct-alias table from the same catalogue used by the command bar. Release tests check command coverage and offline packaging. Any change to behaviour, timing, controls or limits also requires review of this guide before publication; automated labels alone cannot explain new behaviour correctly.
