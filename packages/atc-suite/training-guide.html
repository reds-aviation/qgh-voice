1. Set up and join

  1. Choose Exercise connection, then Open instructor setup. Select QGH, SRE/vectoring or SRA. New QGH sessions allow 1–2 aircraft; SRE/vectoring and SRA allow 1–24. Edit callsign, squawk (four octal digits 0–7), return type, aircraft type, initial bearing, range, heading, altitude, speed, turn rate and vertical rate. Bearing and heading are independent. Defaults use separate levels; check them before starting. PAR is deferred and unavailable in this release.
  2. Select the runway/final track and applicable sensor settings. The synthetic local boundary and centreline are training overlays, not published aerodrome limits.
  3. Create Session keeps the instructor desk open. The controller uses the paired entry page and enters the generated six-digit PIN. Session → Open controller entry optionally opens that same page with the PIN filled in; Request to join is still required. Instructor selects Admit; student selects Ready; instructor selects Start.
  4. Choose the same Exercise connection on both positions. This device / offline requires one PC, the SAME browser profile and the exact same site address. Recommended: two monitors, Windows + P → Extend, with the student in a separate browser window on screen 2. Duplicate exposes the instructor picture. Online room connects different PCs or devices; both need internet and the same six-digit PIN. The instructor admits the student, the student presses Ready, then the instructor starts. The standalone offline kit cannot share a session across separate PCs.
  5. For an extended monitor, select Open / Focus and then Move to Second Display. Allow placement if your browser asks. If unsupported, drag the student window manually. Keep the instructor window open.

Pilot audio is optional, installed-device only, and muted by default. Enable it on the student position if a local voice is available. Captions and simulated transmissions still work when audio is muted or unavailable. The instructor-led exercise is controlled by buttons and keyboard; voice recognition is available in individual QGH.

2. Exercise modes and timing

QGH: existing Normal/U/S exercise flow, default 5× flight clock. Normal uses heading turns; U/S uses left/right NOW and STOP with no heading readback. D/F appears during the pilot transmission and freezes for two real seconds at release. Selecting another aircraft does not change the transmitting source.

SRE/vectoring and SRA: default real-time 1×; optional 5× and 10× accelerate the flight and sensor clock together. Groundspeed remains knots, range NM, turn rate degrees/second and vertical rate ft/min. At 240 kt, one real minute at 1× covers 4 NM in straight flight. Advance One Minute advances every aircraft, not just the selected one. Exercise time begins at 00:00:00 and displays hours, minutes and seconds.

Surveillance/SRA: new exercises use 15 RPM with a four-simulated-second revisit. At 1× this is four real seconds; 5× gives 0.8 real seconds and 10× gives 0.4 real seconds. Returns update on beam crossing. Primary + returns are anonymous. Cooperative secondary □ returns can show sampled identity and track data. They are not continuous truth.

SRA: centreline, distances and 3° descent cues are reference aids. The instructor must command descent; there is no automatic glidepath capture. Heights marked AAL are above aerodrome level, not an operational clearance.

PAR: deferred and unavailable in this release. Use QGH, SRE/vectoring or SRA.

3. Typed commands

Select the aircraft first. Type into Command Bar and press Enter or Execute. Case and repeated spaces do not matter. This is an exact grammar, not free-form RT or callsign addressing. HELP or ? opens the quick reference. Invalid or unavailable commands make no change.

Accepted aliasesEffect / limits

Commands with numbers

  • L 230, LEFT 230, TURN LEFT 230, TURN LEFT HEADING 230; use R/RIGHT for the right variants. Optional TURN and HEADING also work with L/R. Heading must be 0–359°. Unavailable in U/S Compass.
  • SPD 240 or SPEED 240: 60–600 kt, multiples of 5.
  • ALT 7000 or ALTITUDE 7000: infer climb/descent from current level. 500–45,000 ft, multiples of 100.
  • CLIMB 7000, DESCEND 5000, MAINTAIN 7000: TO or AT may precede the number. The direction must match the current altitude; MAINTAIN requires the current level.

Buttons and fields

The turn buttons use Assigned Heading in Normal QGH/radar; U/S buttons turn immediately. Live Speed applies on change. Altitude sets the target; Climb To and Descend To execute it. Continue Heading uses the assigned-heading field. SRA additionally offers Continue Approach, Report Runway Visual and Missed Approach. Terminate is button-only; it ends the exercise and opens debrief. No keyboard shortcut terminates the exercise.

Shortcuts do not run inside inputs, selects, buttons, links or the command bar, while the guide is open, with modifier keys, or on held-key repeats. Finish typing and click a neutral area before using a shortcut. On phones, use buttons; turn the radar display to landscape.

5. Student display controls

QGH: switch QDM/Homing or QTE/True Bearing. Held readings use the frozen release observation, not a new aircraft position. Near overhead, a bearing may be unavailable.

Radar: select range and history Off/3/5, choose data-label fields, minimise labels, and tap a cooperative square to open details. Drag the detail-card handle to declutter. Primary plots have no identity data. Centreline/descent controls can hide only instructor-provided overlays. PAR is deferred in this release. Pilot Audio toggles sound without removing captions.

6. Timing, recovery and debrief

  • Connected means the link is alive. Picture Stale or Simulation Stalled are separate warnings. No Signal in QGH and Awaiting Scan in radar can be normal.
  • A browser processing gap above two seconds pauses the exercise instead of silently losing or jumping flight time. Restore the instructor window and select Resume. This does not prevent device sleep.
  • Refresh the same student window to restore the admitted seat and last safe picture. Audio restarts muted. Use Reconnect for a lost link. If the window was closed or storage is unavailable, instructor can Release Student Seat, admit the new window and start again from the existing aircraft state.
  • Keep the instructor window open. Refreshing the same instructor tab can restore its checkpoint paused, retaining the PIN, student seat and review. Reconnect the controller before Resume. Closing the instructor or losing its heartbeat freezes the student picture. PIN admission expires after 15 minutes while waiting; an active admitted seat can reconnect. Hosted rooms have an eight-hour maximum lifetime.
  • New commands replace obsolete pilot replies. Flight actions execute immediately; audio completion never controls the turn itself. Muted captions use a bounded reading duration. Missing audio completion has a watchdog so D/F cannot stay live forever.
  • Terminate opens debrief: toggle truth, student observations and commands; play/pause, choose replay 1×/2×/3× or scrub time. Restart Exercise returns to setup.

Guide maintenance

The build stamps this guide with the release version and generates the direct-alias table from the same catalogue used by the command bar. Release tests check command coverage and offline packaging. Any change to behaviour, timing, controls or limits also requires review of this guide before publication; automated labels alone cannot explain new behaviour correctly.
