    STEP 04 · SENSOR FLOW

    Use the right picture

    QGH keeps its existing exercise flow and 5× training-clock default. Surveillance, SRA and PAR start at real-time 1×; faster speeds remain optional. D/F stays live for the pilot reply and freezes for two real seconds afterwards, regardless of flight speed. Surveillance and SRA plot on beam crossing. PAR samples its designated aircraft. Set speed and command descent as required; the aircraft does not automatically follow the displayed glidepath.

    If the browser suspends processing for more than two seconds, the exercise pauses instead of skipping flight time. Resume deliberately. Refreshing the same student window restores its seat; audio restarts muted. Use Reconnect for a lost link, or Release Student Seat to admit a replacement window.

    STEP 05 · CONNECTION & SCREENS

    Open the student display, admit, control, review

    Choose This device for offline operation on one PC in the same browser profile; choose Online room for different PCs with internet on both. For the best offline setup press Windows + P → Extend, then put the student in a separate window on screen 2. Do not use Duplicate. Creating a This-device session opens the Student Display. When a second monitor is available, select Move to Second Display and allow window placement when asked. If the browser cannot place windows, move it manually. Enter the PIN, admit the student, wait for Ready, then start. Termination freezes the exercise and aligns truth, observations, commands and replies for debrief.
